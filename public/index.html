Full-Stack App · Node.js + Express + SQLite

Proactive mental-health check-ins, with a human on every escalation.

First Signal is a working, full-stack application: employees submit a daily check-in, an explainable rule-based engine scores risk in real time, low/moderate cases get an instant grounding exercise, and every high-risk case is routed to a human care coordinator. The system never auto-resolves a case.

How the real backend works: passwords are hashed with bcrypt (10 rounds) before storage. Login verifies the hash with bcrypt.compareSync(). A JWT (8h expiry) is returned and stored in memory — sent as Authorization: Bearer <token> on every API call.

    Backend architecture · Express REST API

    Backend functionality

    Express REST API, JWT-authenticated, with a role-guard middleware and a fully explainable scoring module.

    MethodPathAuthPurpose
    POST/api/auth/signupNoneCreate account; employees must send consentGiven: true
    POST/api/auth/loginNoneReturns JWT + user object
    POST/api/checkinsAny logged-inSubmit check-in → returns risk result + intervention or escalation
    GET/api/checkins/meAny logged-inOwn check-in history
    GET/api/checkins/allCoordinator onlyAll employees' check-ins
    GET/api/alertsCoordinator onlyList alerts, filterable by status
    PATCH/api/alerts/:idCoordinator onlyUpdate status and/or notes
    GET/api/reports/summaryCoordinator onlyAggregated stats for dashboard
    GET/api/reports/loginsCoordinator onlyLogin/signup activity log
    GET/api/healthNoneLiveness check

    Risk-scoring engine

    Lives in server/lib/riskEngine.js — rule-based, fully auditable.

    riskScore = phqNorm × 0.5 + moodNorm × 0.2 + sentimentNorm × 0.3  (clamped 0–1)
    ≥ 0.66 → high  ·  0.34–0.65 → moderate  ·  below 0.34 → low
    crisis-phrase match → override to HIGH, floor at 0.85

    🔗 Referential integrity

    Limitations & future work

    • The free-text sentiment layer is a keyword proxy, not a validated clinical instrument.
    • The word list contains at least one duplicate-entry defect (stress/stressed).
    • The crisis-phrase list is intentionally short and literal — paraphrased ideation can fall through.
    • No operational SLA for how quickly an open alert must be reviewed.
    • A pilot validating risk_score against PHQ-9 would be the natural next research step.
